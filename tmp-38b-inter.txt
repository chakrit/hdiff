## Violations

### V1 — `line_height` leaves its value-producing match with `return`

`src/navigation/extent.rs:493-504`:

```rust
let cells = match wrap {
    WrapWidth::At(cells) => cells,
    WrapWidth::Off | WrapWidth::NoPayload => return ScreenLines::ONE,
};
```

The match produces the wrap width, but one arm leaves the function from inside it. Rounds
12, 14 and 16 ruled a value-producing match that exits with `return` a Violation, and
round 37 removed the same shape from `distances_from_previous_change`, `Language::of_header`
and `write_row` in the rendering area. This one came in with round 35's naming of every
`WrapWidth` case. Fix: let each arm finish its job — `WrapWidth::At(cells)` yields the
measured height (one line when the payload fits, else `wrapped_line_count`), and
`Off | NoPayload` yields `ScreenLines::ONE` — so the match is the function's value.

### V2 — same-typed positional arguments that swap silently

Round 36 V2 ruled that two positional arguments of one type, which a caller can swap
without a compile error and silently break behaviour, are a Violation (`ScrollBounds::new`,
after round 13 V9's `FloatingBox`). Three operations in this area still take that shape:

- `WrapWidth::horizontal_range(self, rows_width: Cells, content_width: Cells)`
  (`src/effective_view.rs:67`, called at `src/navigation/extent.rs:135`). Swapped, it
  returns `content_width - rows_width` saturated to zero, so unwrapped rows silently stop
  scrolling horizontally.
- `ScrollExtent::shown(…, offset: ScreenLines, limit: ScreenLines)`
  (`src/navigation/extent.rs:140-146`, called at `src/navigation.rs:84`) and the
  `MeasuredRows::lines_from(offset, limit)` it calls (`extent.rs:308`). Swapped, the pane
  draws from the wrong line for the wrong count.
- `geometry::halfway(start: u16, length: u16)` (`src/geometry.rs:376`, called four times in
  `src/terminal/chrome.rs:98, 99, 181, 208`). Swapped, the popup, the side markers and the
  window markers land off-centre.

Fix: give each pair a named shape the call site spells — for example named fields (as
`ScrollBounds` and `LineWindow { first, total }` already do), or one value that carries
both (a span of a start and a length for `halfway`; the requested window for `shown` and
`lines_from`).
